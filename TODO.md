# PureNT: Детальный TODO и Roadmap разработки

Документ отражает актуальное состояние кодовой базы PureNT (чистая реализация архитектуры Windows NT 6.1 / Windows 7 SP1 x64 на Rust `no_std`), фиксирует недавние изменения и формирует приоритетный список задач для команды.

---

## 1. Что только что сделано (недавние коммиты и текущий диф)

### 1.1. Модуляризация Win32 DLL и честный загрузчик через NTDLL (`1614378`)
- [x] Распилен монолитный `purent-win32.dll` на канонические библиотеки Windows:
  - `purent-ntdll` (`ntdll.dll`): динамический PE-загрузчик пользовательского режима (`LdrLoadDll`, `LdrGetProcedureAddress`), разрешение импортов и релокаций в Ring 3.
  - `purent-kernel32` (`kernel32.dll`): базовые Win32 API управления памятью, потоками и консолью.
  - `purent-kernelbase` (`kernelbase.dll`): реализация разделения подсистем NT 6.1.
  - `purent-msvcrt` (`msvcrt.dll`): C runtime-функции (`malloc`, `free`, `memcpy`, строковые операции).
  - `purent-winbrand` (`winbrand.dll`): функции брендинга Windows 7.
  - `purent-pe`: общий парсер Portable Executable для ядра и пользовательского режима.

### 1.2. NT Драйверная модель, IRP и синхронизация (`4c1748b`)
- [x] Таблица экспортов ядра `purentoskrnl.exe` (`exports.def`) для линковки оригинальных драйверов Microsoft.
- [x] Подсистема ввода-вывода (I/O Manager): структуры `IRP`, `IO_STACK_LOCATION`, диспетчеризация `IoCallDriver` и завершение `IoCompleteRequest`.
- [x] Загрузка и запуск реальных драйверов Windows NT (`null.sys`, `fs_rec.sys`).
- [x] Примитивы синхронизации ядра: `KEVENT`, `KMUTEX`, `FAST_MUTEX`, `KSEMAPHORE`.
- [x] Планировщик потоков с поддержкой приоритетов (0–31), квантов времени и динамического повышения приоритета.
- [x] Каталог встроенных образов процессов (`ps/builtin.rs`).
- [x] Растровый атлас шрифтов для диалоговых окон (`ui_font.rs`, `dialog-ascii.bin`, Noto Sans).

### 1.3. Полноценная подсистема окон Win32 и USER32 (текущий диф)
- [x] **ABI оконной подсистемы** (`crates/purent-ntdef/src/window.rs`): структуры `WindowClass`, `Message`, `PaintStruct`, `Rect`, системный вызов `SYSCALL_PURENT_WINDOW`.
- [x] **Клиентский USER32** (`crates/purent-user32/src/windows.rs`):
  - `RegisterClassExW`, `CreateWindowExW`, `ShowWindow`.
  - Цикл обработки сообщений: `GetMessageW`, `DispatchMessageW`, `DefWindowProcW`, `PostQuitMessage`.
  - Отрисовка: `BeginPaint`, `EndPaint`, `FillRect`, `GetSysColorBrush`.
- [x] **Ядерный Window Manager в Win32k** (`crates/purent-kernel/src/win32k/windows.rs`):
  - Объекты окон `DesktopWindow`, разграничение клиентской и неклиентской (Aero) области.
  - Очереди сообщений потоков `MessageQueue` с поддержкой `WM_PAINT`, `WM_SETFOCUS`, `WM_KILLFOCUS`, `WM_CLOSE`, `WM_QUIT`.
  - Управление фокусом и Z-order.
- [x] **Тестовое многооконное приложение** (`crates/apps/windowdemo`):
  - Создание двух окон, независимая обработка сообщений в цикле, смена фокуса по Tab, заливка фона через системные кисти.
- [x] **Расширение DWM**: поддержка до 4 независимых поверхностей окон (`MAX_WINDOW_SURFACES`).

## 2. Приоритетный TODO-лист

[P0] Интерактивный ввод и мышь ──► [P1] Оконный менеджер и GDI ──► [P2] Файловая система (VFS) ──► [P3] Запуск утилит с диска

### [P0] Интерактивный ввод и мышь (Критический путь)
- [x] **Поддержка мыши PS/2**: Инициализация контроллера 8042, чтение 3-байтовых пакетов с дельтами `(dx, dy)`, отрисовка и стирание аппаратного курсора.
- [x] **Интерактивное перетаскивание окон (Drag & Drop)**: Хит-тест клика по Aero-заголовку (`PointerCapture::DragWindow`, `PointerCapture::DragConsole`), перемещение окон по экрану с обновлением поверхностей и клик по кнопке закрытия `[X]` (`WM_CLOSE`).
- [x] **Управление Z-order и фокусом**: Поднятие окна наверх при клике (`raise_window`), смена фокуса ввода (`set_focus`), отправка `WM_SETFOCUS` и `WM_KILLFOCUS`.
- [ ] **Полноценный ввод с клавиатуры в консоль (`cmd.exe`)**:
  - [ ] Маршрутизация сканкодов в `conhost.exe`: отслеживание нажатий Shift/Ctrl/Enter/Backspace.
  - [ ] Интерактивный терминальный ввод в `cmd.exe`: выполнение команд с клавиатуры в реальном времени.
  - [ ] Передача `WM_KEYDOWN` / `WM_CHAR` в активное окно Win32 с фокусом.
- [ ] **Опционально: Режим USB Tablet (для бесшовного курсора в VM)**:
  - [ ] Подключение `-device usb-tablet` в QEMU для трансляции абсолютных координат без необходимости кликать внутрь окна для захвата курсора.

## 3. Резюме текущего состояния

PureNT успешно выполняет:
1. Загрузку через 64-битный UEFI GOP в честном разрешении **1280×720 TrueColor**.
2. Инициализацию NT ядра, диспетчера памяти, планировщика APIC и системных вызовов.
3. Запуск пользовательских изолированных процессов в Ring 3: `smss.exe`, `dwm.exe` (PID 0x600), `conhost.exe` (PID 0x500).
4. Запуск оригинального Microsoft `cmd.exe` с полным разрешением зависимостей через отдельные `ntdll.dll`, `kernel32.dll`, `kernelbase.dll`, `msvcrt.dll`.
5. Работу оконной подсистемы: регистрацию классов окон, циклы сообщений, отрисовку Aero Glass рамки и обработку GDI.

**Ближайший следующий шаг команды**: закрыть блок **P0** (оживить движение мыши через сброс 8042 / USB Tablet и подключить ввод с клавиатуры в `conhost.exe` / `cmd.exe`).
